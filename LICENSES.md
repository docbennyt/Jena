## 7-Zip

Jena uses the unmodified 7-Zip command-line engine for archive listing, creation, integrity testing, and extraction.

7-Zip is primarily licensed under GNU LGPL 2.1 or later, with BSD-licensed portions and an unRAR restriction for some decompression code. The portable build reproduces the upstream `License.txt` beside the engine at `tools\7zip\License.txt`.

7-Zip source code and license information: https://www.7-zip.org/
