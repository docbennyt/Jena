# Jena v0.3.1 Reliability Verification

> Historical verification record. ADR-002 supersedes generalized internal preview and Explorer-style browsing as a product direction. The evidence below remains valid for the v0.3.1 build and must not be read as a requirement to expand Jena into a file manager.

Date: 2026-10-02

## Scope

This patch addresses three current packaged-app defects only:

- Project Library selection could make Jena appear Not Responding.
- Users could not meaningfully preview images, videos, and documents before cleanup.
- Delete semantics needed to match Windows conventions everywhere filesystem items are managed.

No cloud, AI/MCP, watchers, automation, or roadmap scope was added.

## Root Cause

Project Library discovery previously called synchronous recursive discovery and full project size analysis from UI actions. Large dependency/cache trees could therefore keep the Tkinter main thread from processing window messages.

## Architecture Change

Added a reusable TaskManager with:

- explicit states: QUEUED, RUNNING, CANCELLING, CANCELLED, COMPLETED, FAILED
- cancellation tokens
- worker threads
- queue-based progress/result events
- Tkinter `root.after(...)` polling for UI updates

Project discovery now uses a two-phase model:

- Phase 1: bounded-depth quick root discovery with dependency/cache pruning and streamed results.
- Phase 2: independent project size analysis with cache updates.
